# Zquick

极轻量的 **Windows Explorer 右键级联菜单工具箱**（基于系统原生 .NET Framework 4.8 WinForms，单文件仅 ~150 KB、安装包仅 ~1 MB，Windows 10/11 零运行库开箱即用，支持 Per-Monitor V2 高分辨率缩放），将目录结构查看、按文件夹名重命名子文件、批量加/去前缀、7-Zip 批量压缩、FFmpeg 视频无损旋转及自定义脚本整合到一个可扩展的二级右键菜单中，支持可视化菜单管理、重命名预览确认与一键逆序撤销。

---

## 一、下载与安装

前往 [GitHub Releases](https://github.com/mcxen/Zquick/releases) 下载最新版：

| 分发包 | 体积 | 适用场景 |
| :--- | :--- | :--- |
| **`Zquick-Setup-v*-win-x64.exe`**（推荐） | ~1 MB | Windows 安装向导，支持安装时自动注册右键菜单、卸载时自动清理注册表 |
| **`Zquick-Portable-v*-win-x64.zip`** | ~100 KB | 绿色单文件便携版，解压 `Zquick.exe` 即用（Windows 10/11 免装任何运行库） |

## 二、内置功能与安全机制

| 菜单功能 | 说明 | 安全与体验改进 |
| :--- | :--- | :--- |
| **1. 目录结构概览** | 统计直接子文件夹数、文件数与总体积，弹窗展示目录树并支持一键复制 | 超大目录（>2000行）自动截断防卡死 |
| **2. 子文件夹批量加前缀...** | 弹窗输入前缀（记住历史常用前缀），为直接子文件夹批量添加前缀 | 跳过已包含该前缀或目标冲突项；支持预览与撤销 |
| **3a. 用当前文件夹名重命名子文件** | 将当前文件夹内的子文件按当前文件夹名重命名 | 按扩展名分组，单文件直接命名为 `文件夹名.ext`，多文件自动补零 `文件夹名_01.ext`，跳过隐藏/系统文件，重复运行幂等 |
| **3b. 各子文件夹内文件按文件夹名重命名** | 遍历当前目录下的每个子文件夹，将其内部文件按所属子文件夹名重命名 | 自动补零防排序错乱；彻底避免批处理感叹号 `!` 丢字符问题 |
| **清理指定前缀（可在设置自定义）** | 递归移除子文件与子文件夹名称前匹配的垃圾前缀列表 | 按路径由深到浅安全改名；规则可在界面多行自由配置 |
| **4a. 批量压缩子文件夹（含外层+移入回收站）** | 逐个将子文件夹打包为 `.zip`（压缩包内包含外层文件夹） | 严格校验 `7z.exe` 退出码 `0` 后才将源文件夹**移入回收站** |
| **4b. 批量压缩子文件夹（平铺+移入回收站）** | 逐个将子文件夹内部文件平铺打包为 `.zip` | 严格校验 `7z.exe` 退出码 `0` 后将源文件夹**移入回收站** |
| **4c. 批量加密压缩子文件夹（AES256+保留源）** | 使用 AES-256 加密打包并保留源文件夹 | 不硬编码密码：默认弹窗输入，也可在动作设置中由 Windows DPAPI 加密存盘 |
| **批量无损旋转视频 90° / 270°** | 调用 FFmpeg `-c copy` 无损旋转目录内视频并输出到 `newfiles\` | 自动建输出目录，支持自定义扩展名及 `Metadata` / `DisplayRotation` 模式 |
| **自定义脚本与组合流水线** | 挂载任意 `.bat` / `.ps1` / `.exe`，或将多个动作串联为一键流水线 | 流水线任意步取消时立即中止后续步骤，防止误打包 |

## 三、右键菜单注册与管理

1. 双击打开 `Zquick.exe` 进入管理主界面：
   - **右键菜单管理**：勾选启用项、调整菜单顺序、设置分割线、编辑参数、添加自定义脚本或组合流水线、先选目录「测试运行」。
   - **全局设置**：自定义右键根菜单名称、选择注册位置（文件夹 / 文件夹空白处）、配置 `7z.exe` 与 `ffmpeg.exe` 路径（支持自动检测）。
   - **撤销历史**：查看每次重命名批次与详细路径对照，支持一键逆序还原。
2. 点击右上角 **「同步到右键菜单」** 即刻生效（写入当前用户 `HKCU\Software\Classes`，**无需管理员权限**）。
3. 命令行静默注册/卸载：
   - `Zquick.exe --install`
   - `Zquick.exe --uninstall`

> **Windows 11 提示**：纯注册表级联菜单在 Windows 10 中直接出现在一级右键菜单；在 Windows 11 中位于右键菜单底部的 **「显示更多选项」**（或按 `Shift + 右键` 直接展开）。若移动了便携版 `Zquick.exe` 的存放路径，重新打开软件点一次「同步到右键菜单」即可刷新路径。

## 四、本地编译与发布新版本

### 本地编译（Windows）
需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)（打包安装包需另装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)）：

```bat
build.bat              :: 编译轻量单文件版 (publish\Zquick.exe)
build.bat installer    :: 编译并生成 Windows 安装包 (dist\)
```

### 版本管理与自动 Release
项目遵循 [Semantic Versioning](https://semver.org/spec/v2.0.0.html)，推送以 `v` 开头的 Git 标签即可自动触发 GitHub Actions (`release.yml`) 在 `windows-latest` 上编译并发布 GitHub Release：

```bash
git tag -a v1.0.2 -m "Release v1.0.2"
git push origin v1.0.2
```
